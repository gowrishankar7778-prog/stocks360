About Us

Stocks 360 is an educational website created to help people understand the stock market in a simple and clear way. It includes enhanced accessibility features so that a wider range of users can use it comfortably.

Our Focus

The website is designed with good accessibility practices. Features such as clear structure, keyboard navigation, screen reader support, and a special accessibility mode are included to improve the experience for everyone.

What We Offer

  • Simple explanations about the stock market
  • Educational news and weekly market overview
  • Stock search with live and historical data (after API integration)
  • Enhanced accessibility features
